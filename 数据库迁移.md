# 数据库迁移

+ 备份：

    ```powershell
    New-Item -ItemType Directory -Force -Path backups
    Copy-Item blog.db "backups\blog_before_$(Get-Date -Format yyyyMMdd_HHmmss).db"
    ```

+ 改 `models.py` 前，先看现状

    ```powershell
    sqlite3 blog.db ".schema posts"
    sqlite3 blog.db ".schema admins"
    ```

+ 改 `models.py` 时，同步准备 SQL
  + 先跑 SQL 改表结构：
        ```powershell
        sqlite3 blog.db
        ```
        ```sql
        ALTER TABLE posts ADD COLUMN tags VARCHAR DEFAULT '';
        ```
    + 再改 `models.py` 加对应字段
    + 重启服务 -> 不报错
+ 验证：

    ```powershell
    sqlite3 blog.db "SELECT COUNT(*) FROM posts;"
    ```
